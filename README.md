# READ ME

Install "rust-analyzer"  
Creating a new Rust project
- PowerShell: cargo new project_name
-------------------------------------------------------  
Creating a new Rust file (inside src)
- PowerShell:
  - cd path\to\your\project
  - New-Item src\my_project.rs
-------------------------------------------------------  
Check local package + dependencies for errors
- PowerShell: cargo check
-------------------------------------------------------  
Running the code
- PowerShell: cargo run
-------------------------------------------------------  
Other files will automatically be generated when creating a new Rust project
- target
- .gitignore
- Cargo.lock
- Cargo.toml
